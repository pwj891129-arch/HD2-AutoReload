Read-only weapon identity and ammunition provider
Derived from HD2 HUD+ 0.1.2 by DDRK1NG.
https://www.nexusmods.com/helldivers2/mods/15298

The README bundled with version 0.1.2 expressly permits reuse and modification
with author credit and a link to the Nexus page. That original README is
included unchanged. This is a separate addon, not a re-upload of the HUD.
The original game's boot bytecode and all GUI/HUD rendering are excluded.
Only that version's Lua identity/provider modules and ammunition definitions
are adapted. Later releases are not copied or covered by this permission.
The BootState callback reference is included in source for coexistence tests
only; it is not included in the playable addon resource or release ZIP.

Bingus Shared Loader API and archive format documentation by CowboyBingus:
https://github.com/CowboyBingus/BingusSharedLoader
Requires a separately installed Bingus Shared Loader v18 (API 1).
This addon does not contain or replace the loader.

Bundled stratagem implementation: HD2 Stratagem Hotkeys 0.1.13-test by HD2 Helper.
https://github.com/pwj891129-arch/HD2-Stratagem-Hotkeys
Source commit 86e0d00bb4103c8e91ee56bad1845798e8912eeb.
Sources and offline tests are included under stratagem/; the combined build is
self-contained and does not require that separate repository or addon.
Integration changes defaults and explicit OFF handling, and adds independent
startup and same-frame reload/charge coordination. Existing icon and mouse
release fixes are retained. Game assets and captured references are not included.
